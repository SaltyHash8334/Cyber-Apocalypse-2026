## Methodology

All PoCs follow a structured stage-based approach:

1. **Information Gathering** — artifact discovery and enumeration
2. **Vulnerability Assessment** — identifying security gaps
3. **Exploitation** — gaining access / extracting data
4. **Post-Exploitation** — privilege escalation and pillaging
5. **Privileged Local Information Gathering** — full-access reconnaissance

Each stage includes exact commands, terminal output, descriptive analysis, and security implications.
